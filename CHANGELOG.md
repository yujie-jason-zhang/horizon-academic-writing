## [Horizon-Afterglow 1.0.0] — 2026-08-24

### Added

- Released **Horizon-Afterglow**, the balanced manuscript-polishing profile in the Horizon family.
- Added manuscript understanding, meaning locking, unified diagnosis, one integrated rewrite, fidelity verification, a global reader pass, targeted repair, and an optional consistency audit.
- Added LaTeX/TeX preservation guidance for protected structures, mathematics, numerical bindings, citations, and cross-references.
- Added a dependency-free Python preservation checker with strict, reader-oriented, project, structural-reordering, and advisory style modes.
