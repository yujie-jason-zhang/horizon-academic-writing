# Changelog

All notable public changes to the Horizon academic-writing skills are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and each skill is versioned independently.

## [Unreleased]

## [Horizon-Ember 1.0.0] — 2026-08-24

### Added

- Released **Horizon-Ember**, the focused paragraph-polishing profile in the Horizon family.
- Added reader-oriented, strict/minimal-diff, Chinese-to-English translation, and verification modes for one target paragraph.
- Added local-cohesion, lexical-precision, cognitive-load, rhythm, parallelism, and high-value AI-pattern guidance.
- Added LaTeX/TeX fidelity guidance and a dependency-free preservation checker for claims, numerical bindings, citations, cross-references, mathematics, and protected structures.

## [Horizon-Afterglow 1.0.0] — 2026-08-24

### Added

- Released **Horizon-Afterglow**, the balanced manuscript-polishing profile in the Horizon family.
- Added manuscript understanding, meaning locking, unified diagnosis, one integrated rewrite, fidelity verification, a global reader pass, targeted repair, and an optional consistency audit.
- Added LaTeX/TeX preservation guidance for protected structures, mathematics, numerical bindings, citations, and cross-references.
- Added a dependency-free Python preservation checker with strict, reader-oriented, project, structural-reordering, and advisory style modes.
