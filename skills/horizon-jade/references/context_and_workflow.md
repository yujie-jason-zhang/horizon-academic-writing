# 长文上下文、分批处理与恢复

## 先确定覆盖范围

区分待编辑章节、只读上下文和未提供材料。为原稿记录文件名与可用的版本标识，如修改时间或内容摘要值；原稿保留不动，修订稿另存。

定位优先采用“文件／章／小节／段落序号＋段首短语”，表格采用表号与行列。页码随排版变化，不能作为唯一定位依据。

## 轻量工作记录

多章或分批任务在任务工作目录维护 `jade-context.md`，也可使用已有等效记录。不将作者正文和评审记录混写。没有文件工具时在会话中保留精简状态，并在交接时给出必要摘要。

记录只保留会影响后续决策的信息：

| 类别 | 必要内容 |
|---|---|
| 任务范围 | 用户要求、编辑区域、只读区域、结构或科学校正授权 |
| 原稿版本 | 文件与版本标识；已读取、缺失、提取不完整的章节 |
| 章节地图 | 章节职责、与总问题的关系、真实依赖或并列关系及依据位置 |
| 术语与符号 | 名称、定义、作用域、首次或关键出现位置；待确认冲突 |
| 数值与论断 | 对象、数值及条件绑定，关键论断、限定与证据位置 |
| 处理进度 | 各单元未处理／已改待核／已核验／有待确认项，输出位置与版本 |
| 未决问题 | 问题 ID、原文位置、冲突表述、影响、是否影响继续处理 |

例如术语记录可以是“位姿误差：第 3 章 3.2 定义；与第 4 章配准误差暂不合并”。数值记录要保留指标与条件，不能只列 `0.12、0.18`。

## 分批处理

1. 根据目录和实际提供的摘要、章节引言或总结形成暂定地图，标清哪些仅是概述，不能因此将章正文标为已读。
2. 按小节或相邻段落组分块，尽量不切断定义、公式与解释、结果与条件。每块携带必要相邻上下文，重叠部分标为只读，避免重复改写。
3. 对当前单元完成理解、重写、原文对照与局部通读后，再更新进度和一致性记录。单纯生成候选稿不能标为已核验。
4. 处理下一块时读取与之相关的术语、论断和未决问题；需要判断跨章冲突时回读对应原文，不能仅凭记录中的压缩表述裁决。
5. 完成各块后检查边界衔接，并按实际覆盖章节复核关键贡献、术语和数值。发现问题只修复相关位置，不重新自由重写整篇。

## 中断与恢复

恢复时核对任务范围、用户后续指令、原稿版本及已接受修改。原稿发生变化时，将受影响单元及依赖它的核对结论标为待复核，不盲目沿用旧记录，也不重做无关章节。

不能重新取得某段原文时，可继续不依赖它的工作；该段及受其影响的跨章判断保持未核验。交付时简述已完成范围、未完成项和待确认事项，避免将中断任务报告为全文完成。
