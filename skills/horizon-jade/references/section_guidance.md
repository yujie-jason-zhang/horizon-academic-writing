# 中文论文分章节写作指导

以下是章节任务的诊断参考，不是固定写作模板。按既有章节职责和用户授权调整；原文疑似存在论断问题时，依据 [科学忠实度](scientific_fidelity.md) 区分保真润色与科学校正。

## 摘要

优先保证：

**问题 → 方法动作 → 关键结果 → 证据边界内的结论**

避免：

- 背景过长；
- “具有重要意义”代替结果；
- 贡献词堆砌；
- 结论强于正文。

## 绪论 / 引言

常见有效推进：

**已知背景 → 具体限制 → 实际后果 → 研究问题 → 本文方案 / 贡献**

核心问题：

> 为什么这个问题自然导向本文工作？

## 相关工作

按问题、方法族、关键假设或局限组织。

避免：

“A 做了……；B 做了……；C 做了……”

相关工作段落应帮助读者理解：

> 前人工作为何仍留下本文要处理的具体问题。

## 方法

优先：

- 依赖顺序；
- 对象连续性；
- 输入输出清楚；
- 机制关系清楚；
- 数学定义与文字一致；
- 可复现性。

不要为了“更有故事性”打乱真实算法顺序。

## 实验 / 结果

严格分开：

- 设置；
- 观察；
- 比较；
- 解释。

不要把：

- 未报告显著性依据的提升写成“统计显著”；
- 单一场景写成“普适”；
- 一个指标领先写成“整体优于”；
- 结果相关写成机制被证明。

幅度大小与统计显著性不同。原文已报告小幅但统计显著的提升时，应保留其检验条件和论断，不因幅度小而删掉“显著”。

## 讨论

可以组织为：

**结果 → 解释 → 可能机制 → 与已有研究关系 → 边界 / 局限 → 启示**

解释不等于事实，假设不等于机制证明。

## 结论

只收束：

- 解决的问题；
- 主要方法；
- 核心证据；
- 合理边界内的结论。

不要引入正文没有的新贡献。
