# 中文论文的信息推进与科技语体

## 1. 核心原则

中文学术写作的自然性不等于口语化，也不等于句式复杂。

优先保证：

- 主题稳定；
- 信息逐步推进；
- 技术动作明确；
- 关系可恢复；
- 评价词受证据约束。

## 2. 主题链

优先形成：

`对象 A → A 的新属性 B → 基于 B 的后续处理 C → C 的结果 D`

避免：

`A → 新主语 X → 新主语 Q → 再回到 A`

如确需切换主题，应让切换具有明确理由。

## 3. 连接词病

高频风险词：

- 此外；
- 同时；
- 因此；
- 然而；
- 进一步地；
- 值得注意的是；
- 具体而言；
- 综上所述。

这些词不是禁词。

每次使用前问：

1. 两句之间是否真的存在所标记的关系？
2. 不加这个词，关系是否已经清楚？
3. 如果关系不清，是缺少连接词，还是缺少逻辑桥梁？

## 4. 动词虚化

重点检查：

- 对……进行分析；
- 对……进行处理；
- 实现……的提取；
- 完成……的构建；
- 开展……研究；
- 采用……方法进行……；
- 基于……进行……。

在不损失技术含义时，优先恢复真正动作：

- “对点云进行滤波处理” → “对点云滤波”；
- “实现特征的提取” → “提取特征”；
- “完成局部地图的构建” → “构建局部地图”。

不要机械修改已成为技术术语的名词化表达。

## 5. 项目书式表达

警惕：

- “针对……问题，本文基于……，结合……，采用……，实现……”；
- “具有重要的理论意义和工程价值”；
- “为……提供有力支撑”；
- “为后续研究奠定坚实基础”。

在已有信息范围内优先写清：

- 解决什么具体问题；
- 使用什么机制；
- 得到什么可验证结果。

可删除不承载科学判断的空泛修饰；涉及有效性、性能或贡献的评价不得以“去套话”为由擅自弱化，按 [科学忠实度](scientific_fidelity.md) 处理。无法从原文确定具体机制或结果时，不补造内容来替换套话。

## 6. 长句

不要按字数机械拆分。

一句话承担以下三项以上时，应重点检查：

- 背景；
- 问题；
- 原因；
- 方法；
- 条件；
- 模块；
- 结果；
- 解释；
- 结论。

拆分后应保持主题链，而不是形成碎片化短句。

## 7. 段尾

段尾应优先留下：

- 本段建立的关键事实；
- 对下一段有用的中间判断；
- 必要的边界或后果。

避免模板化收尾：

- “具有重要意义”；
- “提高了系统性能”；
- “验证了方法有效性”；
- “为后续研究提供基础”。
