# 科学忠实度与中文论断强度

## 保真与科学校正的边界

默认语言编辑应保留谁做了什么、因果关系、成立条件、结论范围和证据强度，不擅自增强或弱化。

| 情况 | 默认处理 |
|---|---|
| 语病、冗余、对象指代不清，但含义可确定 | 直接改善表达，保持含义 |
| 没有提供支撑某论断的材料 | 保留论断；任务需要核对时标明未核验，不断言其错误 |
| 已提供材料显示论断可能越界或彼此冲突 | 保留原意，定位疑点，给出待作者确认的具体建议 |
| 用户明确授权校正论断，现有证据足够 | 按证据调整，简述依据和影响 |
| 已获校正授权，但证据仍不足 | 不猜测结论；保留待核验项，继续其他可完成工作 |

例如仅收到“实验验证了该方法的有效性和优越性”，不能自行改成“在三个测试序列中误差更低”：序列数量和比较结果均未提供。若用户提供三个序列的对应误差并要求校正论断，才可据此给出受限的结果表述。

“缺乏支撑材料”与“已有材料不支持”须区分；缺失实验章节不是否定论文论断的依据。

## 论断词按语境核对

“观察到、显示、表明、说明、支持、验证、证明、揭示、解决、保证、普遍适用”携带不同的证据或范围含义，不构成可机械替换的强度阶梯。

- “结果表明”不能随意改为“证明了”。
- “降低”不能改为“消除”，“可能源于”不能改为“原因是”。
- “在测试场景中误差更低”不能泛化成“具有更高精度”。
- “可”可能表示能力、许可或可能性，须依语境保留其含义。
- “显著”可能指统计显著性，也可能是作者的定性表述。保留已有检验条件与 p 值，不因改进幅度小就否定统计显著，也不凭幅度大补称统计显著。

区分观察、解释、机制与结论。“与某机制一致”不等于“证明该机制”。理论结论也需保留假设、量词、充分必要关系、边界条件及证明适用范围。

## 数字绑定

核对数值与指标、单位、方法、数据集、场景、聚合方式及实验条件的组合，不只比数字是否相同。

例如“在室内序列 A 中，方法 M 和基线 B 的均方根误差分别为 0.12 m 和 0.18 m”必须保持 `M—A—均方根误差—0.12 m` 与 `B—A—均方根误差—0.18 m` 两组绑定。

区分百分比与百分点、均值与中位数、绝对差与相对变化、样本数与重复次数。未经授权不自行换算、重算或改变有效数字；不一致时定位报告。

## 术语与符号

不为避免重复而改用近义技术词。例如“定位误差／配准误差／位姿误差”“置信度／可信度／可靠度”可能指不同对象。以作者定义为准，无定义时保留区别并报告疑问。

符号按定义作用域核对。不同章节对同一符号有清楚的局部定义时，不自动视为冲突；定义在同一作用域内不一致或使读者误解时才报告。保留大小写、上下标、正负号、希腊字母和变量含义。

## 引用与公式

句子重排时保持每个引文支持的具体命题；不能因合句把仅支持方法 A 的文献附到方法 A、B 的联合论断。没有文献正文时只核对原稿与候选稿的附着关系，不宣称已核验文献真实性或支持力度。

公式本体、编号与文字解释相互核对。不可因纯文本提取丢失上下标或公式对象而用猜测补齐。Word 中的公式、引用域和交叉引用保护见 [Word 工作流](word_workflow.md)。

## 错误归属

修订引入的漂移须回退或局部修复后再交付。原稿中的数值冲突、证据疑点和定义缺失须保留可定位记录；不能为了让检查全部“通过”而擅改原文。
